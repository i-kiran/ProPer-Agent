You are an expert annotator for programming tasks. Extract latent dimensions from:
(1) User query, (2) Solution code.

## Objectives
- Infer concise, latent and trivially stated aspects.
- Avoid speculation beyond weak, text-grounded inference.
- For USER ASPECTS, base extraction on the following interpretive axes:
    • Goal Intent  (what action the user wants)
    • User State   (expertise, uncertainty, preferences, constraints)
    • Task Structure Cues  (the type of cognitive/computational task implied)
    • Constraint Indicators (explicit or implicit requirements)
    • Missing-Information Signals (gaps or underspecification)
- For SOLUTION ASPECTS, focus only on technical characteristics of the code.
- Output valid JSON only.

## Inputs (verbatim strings)
- query: {query}
- solution: {gold_response}

## Aspect definitions
- aspect = {name, value, justification}
- justification must cite evidence (verbatim substring or "null" if none).

## Canonical aspect types (preferred, explore more wherever possible)

User:
  goal_intent, user_state, expertise_level, uncertainty_indicator,
  preference_constraint, constraint_awareness, contextual_signal,
  missing_information, task_structure

Solution:
  algorithm_pattern, data_structures, complexity_time, complexity_space,
  optimization_decision, robustness, constraint_handling, determinism,
  library_usage, correctness_risk

## Output schema (must match exactly)
{
  "user_aspects": [
    {"name": str, "value": str, "justification": str}
  ],
  "solution_aspects": [
    {"name": str, "value": str, "justification": str}
  ]
}

## Extraction procedure (silent; do NOT output steps)
1) From the query: infer user-side aspects based only on the axes above and beyond.
2) From the solution: infer technical patterns and properties of the implementation.
3) Produce as many distinct, meaningful aspects as supported by the text.
4) Prefer canonical names; avoid trivial restatement.
5) Remove duplicates.

## Style constraints
- Be concise. No chain-of-thought.
- Use US-ASCII.
- Output JSON only, no extra text.
