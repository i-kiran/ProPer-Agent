Query: Given a large integer N (up to 1e6), find the maximum number of distinct binary strings of length N that can be formed such that no two strings are identical and no string is a prefix of another string? Can we use a sliding window approach to find a subsequence in a string such that the sum of characters in the subsequence is divisible by a given number? What is the maximum number of non-overlapping rectangles that can be formed using a set of N points in a 2D plane, given that each point is represented by an integer coordinate x and y, and each rectangle must have a width and height of at least a and b respectively, where a and b are given integers? What is the maximum number of non-overlapping rectangles that can be formed?
Solution: #1538g
import sys
for _ in range(int(input())):
    x,y,a,b=map(int,sys.stdin.readline().split())
    if a==b:
        print(min(x,y)//a)
        continue
    ans=0
    x,y=max(x,y),min(x,y)
    a,b=max(a,b),min(a,b)
    if b*x>a*y:
        x=int(a*y/b)
    xx=(a*x-b*y)//(a*a-b*b)
    yy=(a*y-b*x)//(a*a-b*b)
    ans=xx+yy
    yy1=(y-b*xx)//a
    xx1=(x-b*yy)//a
    ans=max(ans,xx+yy1,xx1+yy)
    print(ans)
